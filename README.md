
# All-In-One Web Utility Suite 🚀

A modern, fast, and user-friendly web application designed to handle your everyday digital tasks. Edit PDF documents, convert files, and download media content from popular social media platforms including Instagram, YouTube, and Facebook—all in one place.

---

## 🛠️ Key Features :- 

### 📄 PDF Tools
- **PDF Editor:** Add text, shapes, signatures, and annotations directly to your PDF files.
- **Merge & Split:** Combine multiple PDFs into a single file or extract specific pages.
- **Compress & Convert:** Reduce PDF file sizes and convert PDFs to/from images (PNG, JPG) or Word documents.

### 📽️ Media Downloader
- **Instagram Downloader:** Easily download Instagram Reels, Posts, IGTV videos, and Carousel photos in high resolution.
- **YouTube Downloader:** Save YouTube videos in multiple resolutions (1080p, 720p, 4K) or extract audio directly as MP3.
- **Facebook Downloader:** Download public Facebook videos and reels in HD quality.
- **Multi-Platform Support:** Built-in modular design to easily add support for additional platforms (TikTok, Twitter/X, Pinterest).

---


## 🧰 Tech Stack

- **Frontend:** React.js / Next.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Processing Libraries:** `pdf-lib` / `pdfjs-dist` (for PDF manipulation), `ytdl-core` / `ffmpeg` (for media processing)
- **Deployment:** Vercel / Render

---

## 📦 Prerequisites

Make sure you have the following installed on your machine before running the project:-

- [Node.js](https://nodejs.org/) (v18.0.0 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [FFmpeg](https://ffmpeg.org/) (required for video/audio processing on the backend)
